# 圖表面板說明

`chart.sh 2303` 產生的圖表從上到下共四個面板：

---

## Panel 0：K 線 + 通道（主圖）

| 元素 | 顏色 | 說明 |
|---|---|---|
| K 線（紅/綠） | 紅漲綠跌 | 台灣標準：紅 = 收盤 > 開盤（漲），綠 = 收盤 < 開盤（跌） |
| 成交量 | 柱狀圖 | 主圖下方灰色柱，數字越大成交量越高 |
| **Bollinger Bands** | 藍色虛線 | 20 日 ±2 倍標準差。價格觸及上軌 = 超買，觸及下軌 = 超賣 |
| **Keltner Channels** | 橘色實線 | 20 日 ±1.5 倍 ATR。與 BB 搭配用於判斷 Squeeze |

**Squeeze 判斷**：當 BB 與 KC 重疊（BB 在 KC 內部）→ Squeeze ON（準備突破）

---

## Panel 1：Momentum（動能）

| 顏色 | 意義 |
|---|---|
| 青色 | Momentum 正值且上升（動能增強） |
| 藍色 | Momentum 正值但下降（動能減弱） |
| 紅色 | Momentum 負值且下降（動能轉弱） |
| 暗紅 | Momentum 負值但回升（跌勢收斂） |

**零軸以上** = 動能偏多，**零軸以下** = 動能偏空

**Fired（爆發）**：Momentum 從壓縮狀態突然轉正值 → 強烈買入訊號

---

## Panel 2：SQZ（Squeeze 狀態）

| 顏色 | 意義 |
|---|---|
| 黑色 | Squeeze ON — BB 在 KC 內部，壓縮中 |
| 灰色 | Squeeze OFF — 正常波動 |

Squeeze ON → 醞釀突破，配合 Momentum 方向判斷突破方向

---

## Panel 3：RS Index（相對強勢）

| 線 | 顏色 | 意義 |
|---|---|---|
| RS Index | 紫色 | 個股 ÷ 大盤，基期 100 |
| EMA20 | 紅色 (半透明) | 短線 RS 趨勢 |
| EMA60 | 藍色 (半透明) | 中長線 RS 趨勢 |

- **100 基準線** = 與大盤同步
- **高於 100** = 累計跑贏大盤
- **低於 100** = 累計跑輸大盤
- RS 向上突破 EMA20 → 短線開始跑贏
- EMA20 突破 EMA60（金叉）→ 相對強勢結構確立

---

## 訊號對應

| Signal | 條件 |
|---|---|
| 強烈買入 (爆發) | Fired + Momentum > 0 |
| 買入 (動能增強) | Momentum > 0 且上升 |
| 觀察 (跌勢收斂) | Momentum < 0 但回升 |
| 賣出 (動能轉弱) | Momentum < 0 且下降 |
| 強烈賣出 (跌破) | Fired + Momentum < 0 |
